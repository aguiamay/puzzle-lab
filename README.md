# Puzzle Lab

```sh
npm ci
npm run dev
```

Abra http://localhost:3000. Requer Node >=20.9.

Verificações: `npm run typecheck`, `npm run lint`, `npm run build`, `npm run audit:geometry`. Extração de pesquisa: `npm run audit:geometry -- --catalog`.
